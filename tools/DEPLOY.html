飆股篩選器 - 雲端部署教學

部署到 Render（推薦）

費用

  • 免費方案：$0（15分鐘沒人用會休眠，喚醒要等30秒）
  • Starter 方案：$7/月（約NT$220）（不休眠，長期推薦）

步驟

第一步：建立 GitHub 帳號和倉庫

  1. 到 https://github.com 註冊帳號（如果還沒有的話）
  2. 點右上角「+」→「New repository」
  3. 名稱輸入 stock-screener
  4. 選 Private（私人）
  5. 點「Create repository」

第二步：上傳程式碼到 GitHub

在電腦上打開 CMD 或終端機，執行以下指令：

cd D:\python程式開發\飆股篩選器

# 初始化 Git
git init
git add .
git commit -m "飆股篩選器 v3.0"

# 連結到你的 GitHub（把 YOUR_USERNAME 換成你的帳號）
git remote add origin https://github.com/YOUR_USERNAME/stock-screener.git
git branch -M main
git push -u origin main

第三步：在 Render 部署

  1. 到 https://render.com 用 GitHub 帳號登入
  2. 點「New +」→「Web Service」
  3. 連結你的 GitHub 帳號，選擇 stock-screener 倉庫
  4. 設定：
    • Name: stock-screener
    • Region: Singapore（最近台灣）
    • Branch: main
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: gunicorn -c gunicorn_config.py app:app
  5. 選方案：
    • 先選 Free 測試
    • 確認可用後升級到 Starter ($7/月)
  6. 點「Create Web Service」
  7. 等待 3~5 分鐘部署完成
  8. 完成後會得到網址，例如：https://stock-screener-xxxx.onrender.com

第四步：手機使用

  1. 手機開瀏覽器，輸入 Render 給你的網址
  2. Chrome → 選單 → 加入主畫面
  3. 桌面會出現 App 圖示，隨時隨地可以用！

之後更新程式

每次修改完程式碼：

cd D:\python程式開發\飆股篩選器
git add .
git commit -m "更新說明"
git push

Render 會自動偵測到變更並重新部署（約2~3分鐘）。

其他平台選項

Railway（用量計費）

  • 網址：https://railway.app
  • 費用：$5 起，用多少算多少
  • 優點：介面漂亮、部署快
  • 缺點：流量高時費用不好預估

Fly.io（進階）

  • 網址：https://fly.io
  • 費用：$5/月起
  • 優點：全球節點、速度快
  • 缺點：需要用 CLI 工具，稍微複雜

VPS 主機（最自由）

  • Linode / DigitalOcean / Vultr
  • 費用：$5/月起
  • 優點：完全控制、可跑多個服務
  • 缺點：需要會 Linux、自己維護

自訂網域（選配）

如果想要自己的網址（例如 stock.yanbenwei.com）：

  1. 到 Namecheap / GoDaddy / Gandi 買網域（約 NT$300~500/年）
  2. 在 Render 設定 → Custom Domain → 加入你的網域
  3. 到網域商的 DNS 設定，加入 CNAME 記錄指向 Render
  4. 完成！

常見問題

Q: 免費方案夠用嗎？
A: 如果只是收盤後看結果可以用免費的。但盤中即時更新需要服務不休眠，建議 Starter。

Q: 手機不用裝 App？
A: 對，用 PWA 的「加入主畫面」功能，看起來跟 App 一模一樣。

Q: 資料會不會外洩？
A: GitHub 倉庫設為 Private，Render 上的服務有 HTTPS 加密，安全無虞。

Q: 可以多人一起用嗎？
A: 可以，把網址分享給別人就能用。Starter 方案同時 10~20 人沒問題。
