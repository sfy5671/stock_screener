📋 上架流程概覽

  1. 準備帳號與費用（Apple Developer + Google Play Console）
  2. PWABuilder 打包（一鍵生成 iOS + Android package）
  3. 準備上架素材（截圖、描述、icon）

  5. 審核通過上架

Step 1：帳號與費用

平台費用必備工具審核時間
iOS App Store USD $99/年 Mac + Xcode + Apple ID 1-3 天
Android Google Play USD $25 一次性 瀏覽器 + Google 帳號 幾小時 - 7 天
建議優先 Google Play：費用便宜、不需 Mac、審核快。實測通過後再投資 iOS。

申請 Apple Developer Program

  1. 用 Apple ID 登入 developer.apple.com/programs
  2. 選擇「Individual」個人方案 USD $99/年
  3. 填入身分證明資訊 + 信用卡
  4. 等 1-2 個工作天驗證（Apple 會打電話確認）

申請 Google Play Console

  1. 用 Google 帳號登入 play.google.com/console/signup
  2. 選「個人開發者」
  3. 付一次性 USD $25
  4. 填入聯絡資訊 → 即可開始上架

Step 2：PWABuilder 打包

PWA → 原生 App 的橋樑。免費線上工具，一鍵生成 iOS + Android 安裝包。

網址：https://www.pwabuilder.com

操作步驟

  1. 打開 PWABuilder.com
  2. 輸入網址：https://stock-screener-pro-5wpz.onrender.com
  3. 點 Start 等驗證跑完（會顯示 PWA / Manifest / Service Worker 三個分數，目標都要 80+）
  4. 右上角點 Package For Stores

Android Google Play 打包

  1. 選 Android → Generate Package
  2. 設定畫面：
    • Package ID：com.songfamily.stockscreener（一旦上架不能改！）
    • App name：飆股篩選器
    • Launcher name：飆股篩選
    • App version：1.0.0（versionCode 從 1 開始）
    • Display mode：Standalone
    • Status bar color：#0a1628
    • Signing key：產生新的（重要！保存好簽名金鑰，後續更新版本必須用同一把）
  3. 下載 飆股篩選-android.zip（內含 .aab 上架檔 + signing key）
⚠️ Signing Key 絕對不能遺失！遺失後永遠無法更新已上架 App，只能下架重新上架（重新累積使用者）。
建議：壓縮包 + 私人 GitHub repo 各備份一份 + .keystore 密碼用 1Password 存。

iOS App Store 打包

  1. 選 iOS → Generate Package
  2. 設定畫面：
    • Bundle ID：com.songfamily.stockscreener
    • App name：飆股篩選器
    • App version：1.0
  3. 下載 飆股篩選-ios.zip（Xcode 專案壓縮包）
  4. 解壓 → 用 Mac 上的 Xcode 打開 .xcworkspace 檔案
  5. 在 Xcode 內：
    • 選你的 Apple Developer Team
    • 修改 Bundle Identifier（如已被佔用）
    • Archive → Distribute App → App Store Connect → Upload

Step 4：審核 & 上架

Android Google Play 提交

  1. 登入 Play Console
  2. 建立新應用程式 → 上傳 .aab 檔案
  3. 填寫商店資訊（描述、截圖、icon、隱私政策連結）
  4. 內容分級問卷（金融類選「不含成人內容」）
  5. 目標對象：13+（金融類不能 13 以下）
  6. 送出審核 → 約 1-7 天

iOS App Store 提交

  1. 登入 App Store Connect
  2. 建立新 App（記得 Bundle ID 跟 Xcode 上傳的一致）
  3. 填寫商店資訊（描述、截圖、icon、隱私政策連結）
  4. App Review Information：填一個審核員的測試帳號（本 App 不需登入，留 demo 用 email 即可）
  5. 填 Notes for Review：
Notes for Review 建議內容：

This is a Taiwan stock technical analysis tool that aggregates publicly available data from TWSE (Taiwan Stock Exchange) OpenAPI and Yahoo Finance. The app does NOT provide investment advice — it only displays technical indicators and screening results for educational purposes. No user account is required. The disclaimer is shown at the bottom of every page. Privacy policy is at /privacy route.
  1. 送出審核 → 約 1-3 天
金融類 App Apple 審核重點：
  • 明確的免責聲明（已有 ✓）
  • 隱私政策 URL（已有 ✓）
  • 不能宣稱「保證獲利」「最準預測」（描述要避開）
  • 資料來源要寫清楚（TWSE / Yahoo Finance）

Step 5：更新版本

後續更新流程

  1. 修改程式碼 → push GitHub → Render 自動部署
  2. 本機跑 PWABuilder 重新生 zip（用同樣的 Package ID / 簽名金鑰，version 遞增）
  3. Play Console / App Store Connect 上傳新版本
  4. 填「更新內容」（What's New）
  5. 送審 → 通過後使用者會收到更新通知
PWA 部分（網頁內容）不需重新上架就會更新——只要 push GitHub，使用者開 App 就拿到新版。
只有改 manifest / icon / native 設定時才需要重打包送審。

附錄：常見問題

Q：Apple Developer $99 第二年不續費會怎樣？

A：App 會被下架，但已下載的使用者還能繼續用。續費後 App 自動恢復上架，不需重新審核。

Q：可不可以一個帳號上架多個 App？

A：可以。$99 是「Developer Program」費用，不限 App 數量。

Q：Privacy Policy URL 一定要嗎？

A：是。Apple + Google 都強制要求。本專案已建立 /privacy 路由，URL：https://stock-screener-pro-5wpz.onrender.com/privacy

Q：審核被拒怎麼辦？

A：Reviewer 會給原因，最常見：(1) 截圖跟功能不符 (2) 描述含禁用字 (3) 隱私政策連結失效。修正後重新送即可，不需重新付費。

Q：免費 vs 付費 App？

A：免費（無 IAP）最簡單。若要收費或內購（unlock 進階功能），需另外設定 IAP 商品。建議第一版先免費上架累積使用者。
