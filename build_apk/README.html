飆股篩選器 - 手機安裝方式

方法一：PWA 安裝（推薦，最簡單）

  1. 手機與電腦連同一個 WiFi
  2. 電腦執行 python app.py
  3. 手機瀏覽器開啟 http://你的電腦IP:5000
  4. Android Chrome: 右上角選單 → 加入主畫面
  5. iPhone Safari: 分享按鈕 → 加入主畫面

優點：不需要打包，隨時跟電腦同步更新

方法二：APK 打包（Android 專用）

步驟一：安裝 Node.js

到 https://nodejs.org 下載安裝 LTS 版本

步驟二：安裝 Bubblewrap

npm install -g @aspect-build/aspect-cli @nicolo-ribaudo/chokidar-2
npm install -g @nicolo-ribaudo/chokidar-2
npm install -g @nicolo-ribaudo/chokidar-2

使用 TWA（Trusted Web Activity）方式

最簡單的方式是用 TWA 將 PWA 包成 APK：

  1. 確保你的網站可以從手機存取（用 ngrok 或內網 IP）
  2. 使用 PWABuilder 線上工具
  3. 或用以下步驟手動打包

最簡單的方式：用 PWABuilder

  1. 開啟 https://www.pwabuilder.com/
  2. 輸入你的網站網址
  3. 點擊「Package for stores」→ Android
  4. 下載 APK 檔案

注意事項

  • APK 只是個瀏覽器殼，實際資料還是從電腦伺服器取得
  • 電腦必須開著 python app.py 才能使用
  • 如果要讓外網也能用，可以用 ngrok 將本機服務暴露到公網
