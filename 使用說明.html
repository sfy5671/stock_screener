系統簡介

飆股篩選器 v3.1 是一套台股技術分析選股工具，支援全上市/上櫃股票篩選，透過多種技術指標與籌碼面資料，快速找出真正具備飆股特徵的潛力標的。

  • 全市場掃描 一次預篩全上市 + 上櫃約 2000 檔
  • 五大策略模式 飆股 / 高勝率 / 當沖 / 隔日沖 / 全模式合併
  • 籌碼面整合 換手率、連續法人買超、本益比、融資融券
  • PWA 支援 手機加入主畫面，隨時隨地用

v3.1 改造重點

痛點：舊版飆股模式（v3.0）用的是常見技術指標組合（均線多頭、KD金叉、MACD翻多、RSI 50~80、布林突破），訊號太普遍，全市場每天幾百檔通過，不夠精準。

解法：v3.1 重寫飆股策略，改用「真飆股特徵」—— 換手率異常、乖離率不過熱、法人連續性買超、底部突破帶量等指標。

篩選流程

  1. 第一階段：預篩（約 2~3 秒）
    • 從證交所/櫃買中心一次抓全市場當日行情
    • 依最低股價、最低成交量篩出候選
    • 取前 N 名候選股
  2. 第二階段：深度分析（多線程並行）
    • 對候選股逐一抓取歷史 K 線（Yahoo Finance）
    • 計算技術指標（RSI、KD、MACD 等）
    • 套用選擇的策略模式與進階條件
    • 計算綜合分數並排序
  3. 呈現結果
    • 依分數排序顯示符合條件的股票
    • 可點選查看 K 線圖

飆股策略詳解（v3.1）

飆股模式共 7 個條件，每命中 1 個得 1 分，總分越高越有飆股潛力。

#條件意義
1均線多頭排列
MA5 > MA10 > MA20 > MA60		多頭趨勢結構成形
2站上 20 日均線
收盤 > MA20		中短期趨勢仍站在多方
3換手率 3~25%
今日成交量 ÷ 流通股數		活躍但未過熱（飆股甜蜜區）
4乖離率(MA20) 0~15%
(現價 − MA20) ÷ MA20		強勢但未過熱（避開追高風險）
5連續法人買超 3 日
外資或投信		主力連續進場，非單日噪音
6爆量突破 20 日新高
收盤創 20 日高 + 量 > 均量 1.5x		量價雙確認的突破，可信度高
7量能持續放大
5日均量 > 20日均量 × 1.5		整體成交動能正轉強

解讀建議：

  • 5+ 分：飆股候選，宜深入研究（看 K 線、查產業基本面）
  • 3~4 分：強勢股觀察名單，可列入追蹤
  • <3 分：條件不足，觀望

關鍵指標解讀

📊 換手率（Turnover Rate）

定義：今日成交量 ÷ 流通股數 × 100%

反映「籌碼換手」的劇烈程度，是飆股辨識最重要的單一指標。

區間意義解讀
< 1%冷門股沒人交易，難以推升
1 ~ 3%正常股一般大型股的日常活躍度
3 ~ 10%飆股甜蜜區主力正在換手、籌碼正在重整
10 ~ 15%過度活躍已進入急漲段，需注意追高
> 15%過熱警示可能在出貨，建議觀望或減碼

📐 乖離率 BIAS(MA20)

定義：(現價 − MA20) ÷ MA20 × 100%

反映股價與 20 日均線的偏離程度，判斷「強勢」與「過熱」的尺規。

區間意義解讀
< −10%嚴重超賣跌深可能反彈，但需配合其他訊號
−5% ~ 0%接近均線站穩可承接，跌破則注意停損
0% ~ +15%強勢區多頭主升段，飆股啟動到主升常見
+15% ~ +25%偏熱持股可續抱，但別再追高
> +25%過熱警示修正風險高，宜分批獲利了結

👥 連續法人買超天數

從證交所 T86 抓最近 5 個交易日，計算外資 / 投信「連續正買超」的天數。

  • 0~2 日：單日噪音，不具參考性
  • 3~4 日：法人持續性建倉，主力進場訊號
  • 5 日以上：強烈共識，搭配技術面通常持續性更佳

外資與投信「同步」連續買超時，比單一法人更可靠。

💰 本益比（PE）

來源：證交所 BWIBBU_ALL（每日更新）。雖然飆股常本益比偏高，但極端值（>100 或本益比為負）需小心題材股風險。

📉 融資融券

來源：證交所 MI_MARGN。融資餘額快速增加配合股價上漲 → 散戶追高訊號；融券大增 + 股價穩 → 軋空題材。

進階篩選條件

選好策略模式後，還可勾選下列「進階條件」做交集篩選 —— 勾選後只顯示通過該條件的股票。

條件說明可調參數
近期漲停板N 日內出現漲停（≥+9.5%）天數（預設 5）
近期跌停板N 日內出現跌停（≤-9.5%）天數（預設 5）
連續上漲 / 下跌連續 N 日收紅 / 收黑天數（預設 3）
創 N 日新高突破最近 N 日最高價天數（預設 60）
量縮整理今日量 < 20 日均量 × 50%—
跳空上漲今日最低價 > 昨日最高價—
均線黃金交叉5MA 上穿 20MA—
週漲幅達標近 5 日漲幅 ≥ N%%（預設 10）
月漲幅達標近 20 日漲幅 ≥ N%%（預設 20）
價漲量增收紅且今量 > 昨量—
量價背離價創新高但量萎縮（反轉警示）—
連續量增連續 N 日成交量遞增天數（預設 3）

K 線圖

  • 支援週期切換：1 分 / 5 分 / 15 分 / 30 分 / 日 K / 週 K
  • 顯示四條均線：MA5 / MA10 / MA20 / MA60（可獨立勾選顯示）
  • 下方附成交量柱狀圖（紅 = 收高、綠 = 收低）
  • 自動標註進場 / 離場訊號（▲ 紅色 = 進場、▼ 綠色 = 離場）
  • 從篩選結果點任意股票卡片可直接跳到 K 線圖頁籤

訊號規則：至少 2 個技術指標同時確認才標記（KD 交叉 + MACD 翻多 + RSI(2) 反彈 + 布林反彈 + 均線交叉 + 爆量長紅/長黑），同方向訊號至少間隔 3 根 K 棒，買賣衝突時不標記。

本機執行

環境需求

  • Python 3.8+
  • 安裝依賴：pip install -r requirements.txt

啟動

cd "D:/python程式開發/飆股篩選器-OK"
python app.py

開啟瀏覽器 http://localhost:5000

主要依賴

  • flask — Web 框架
  • yfinance — Yahoo Finance 歷史數據
  • pandas / numpy — 數據分析計算
  • requests — 證交所/櫃買中心 API
  • gunicorn — 生產環境 WSGI 伺服器

部署步驟

  1. 建立 GitHub 帳號，建立 Private 倉庫 stock-screener
  2. 將程式碼推送到 GitHub： 
    git init
git add .
git commit -m "飆股篩選器 v3.0"
git remote add origin https://github.com/YOUR_USERNAME/stock-screener.git
git push -u origin main
  3. 到 Render.com 用 GitHub 登入
  4. New → Web Service，選擇倉庫
  5. 設定：
    • Region: Singapore
    • Runtime: Python 3
    • Build: pip install -r requirements.txt
    • Start: gunicorn -c gunicorn_config.py app:app
  6. Create Web Service，等待 3~5 分鐘
  7. 得到網址如 https://stock-screener-xxxx.onrender.com

之後更新

git add .
git commit -m "更新說明"
git push

Render 自動偵測變更並重新部署（約 2~3 分鐘）。

手機安裝（PWA）

  1. 手機瀏覽器開啟 Render 網址
  2. Chrome 選單 → 「加入主畫面」
  3. 桌面出現 App 圖示，隨時可用
  4. 看起來跟原生 App 一模一樣

APK 打包

專案內 build_apk/ 資料夾包含 Capacitor 打包設定，可產出 Android APK。

另有 Google Play 和 iOS 封裝套件可用於上架。

常見問題

Q: 免費方案夠用嗎？

A: 收盤後看結果可用免費的。盤中即時更新需要服務不休眠，建議 Starter ($7/月)。

Q: 手機不用裝 App？

A: 對，用 PWA「加入主畫面」功能，看起來跟 App 一模一樣。

Q: 資料會不會外洩？

A: GitHub 設為 Private，Render 有 HTTPS 加密，安全無虞。

Q: 可以多人一起用嗎？

A: 可以，分享網址就能用。Starter 方案同時 10~20 人沒問題。

Q: 可以自訂網域嗎？

A: 可以。在 Render 設定 Custom Domain，DNS 加 CNAME 記錄指向 Render 即可。
