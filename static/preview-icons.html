飆股篩選器 App Icon - 3 方向比較

看「實際縮小到 60x60 / 90x90 / 120x120 後」哪個還辨識得出來才是好 icon

挑選原則：App icon 在 home screen 上通常顯示 60-120px，要在這個小尺寸下還能一眼認出。如果縮小後變一團模糊，那設計太複雜了。

方案 A — 金色 K 線（漸升）

4 根金色蠟燭由低到高，最右一根帶光暈。傳統金融工具最直覺的視覺。

方案 B — 金色上升箭頭

抽象金色曲線從左下到右上構成箭頭，極簡有力。最現代、最像國際金融 App。

方案 C — 金色雷達掃描

圓形雷達+掃描線，雷達內亮點表示「掃描到的股票」。最符合「篩選器」概念。
